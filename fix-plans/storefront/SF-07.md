## Nguyên nhân

`PaymentServiceClient.java:21-22` gọi `POST /api/v1/payments/vnpay`, nhưng payment-service không có đường dẫn này. `PaymentController.java:46-54` chỉ có `POST /api/v1/payments` cho cả COD và VNPAY. Feign nhận lỗi, `OrderServiceImpl.java:506-509` đổi thành `INTERNAL_ERROR` nên client thấy 500.

Có thêm một điểm lệch về dữ liệu: controller trả `PaymentInitiationResponse(payment, vnPay)`, còn client đang mong URL nằm ngay trong `data`. Chỉ sửa đường dẫn thì `paymentUrl` sẽ là `null`.

## Thay đổi

### 1. `services/order-service/.../client/PaymentServiceClient.java`, dòng 20-22

```diff
-    // Opens a VNPay payment, returning the hosted-checkout URL to redirect the customer to.
-    @PostMapping("/vnpay")
-    ApiResponse<VnPayUrlSummaryResponse> initiateVnPay(@RequestBody CreatePaymentFeignRequest request);
+    // The same endpoint opens a VNPay payment; its redirect URL comes back in the "vnPay" part.
+    @PostMapping
+    ApiResponse<VnPayInitiation> initiateVnPay(@RequestBody CreatePaymentFeignRequest request);
+
+    record VnPayInitiation(VnPayUrlSummaryResponse vnPay) {}
```

**Vì sao sửa ở order-service:** contract của payment-service đang đúng và đã được công bố, chỉ bên gọi viết sai. Thêm endpoint `/vnpay` sẽ tạo ra hai đường dẫn cho một việc.

**Vì sao dùng record lồng:** chỉ phần gọi này cần hình dạng đó, nên không tạo file DTO mới. Jackson bỏ qua trường `payment` không dùng tới, giống cách các bản DTO cục bộ khác của service đang làm.

### 2. `services/order-service/.../service/impl/OrderServiceImpl.java`, dòng 500-505

```diff
-            ApiResponse<VnPayUrlSummaryResponse> response = paymentServiceClient.initiateVnPay(request);
-            if (response == null || response.data() == null) {
+            ApiResponse<PaymentServiceClient.VnPayInitiation> response = paymentServiceClient.initiateVnPay(request);
+            if (response == null || response.data() == null || response.data().vnPay() == null) {
                 throw new AppException(
                         ErrorCode.INTERNAL_ERROR, "payment-service returned no VNPay URL for order " + request.orderId());
             }
-            return response.data();
+            return response.data().vnPay();
```

**Vì sao thêm kiểm tra `vnPay() == null`:** `PaymentInitiationResponse` dùng chung với COD, nơi `vnPay` là `null`. Kiểm tra này giữ nguyên thông báo lỗi rõ ràng, tránh `NullPointerException` ở dòng 488.

**Không cần sửa thêm:**

- `FeignClientConfig` đã gắn `X-Internal-Token`, cần cho `InternalTokenFilter` của payment-service.
- `CreatePaymentFeignRequest` trùng trường với `CreatePaymentRequest`.
- `CheckoutScreen.tsx:138-142` đã đọc `paymentUrl` từ phản hồi của order-service, không đổi.

### 3. `services/order-service/src/test/.../OrderServiceTest.java`, thêm test

Dựng đơn hàng theo cách các test hiện có đang làm.

