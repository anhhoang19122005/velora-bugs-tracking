## Nguyên nhân

Có hai lỗi hiển thị riêng biệt:

1. **Thương hiệu:** thương hiệu đúng là **Velora**. Khung trang hồ sơ, màn hình tải và logo trang đăng nhập đã đúng, nhưng header, footer, trang chủ, trang hỗ trợ và tiêu đề tab vẫn ghi "Taschen", tên của mã nguồn dự án.
2. **Lỗi dấu:** `.display` dùng `font-serif` (`globals.css:126-129`), còn `--font-serif` là Georgia (`globals.css:60`). Georgia thiếu ký tự như `ồ`, nên trình duyệt lấy ký tự đó từ font khác và chữ bị lệch kiểu. Lớp `.display` đang được dùng ở 13 chỗ.

## Thay đổi: lỗi dấu

### 6. `src/app/[locale]/layout.tsx`, dòng 12, 15-19 và 44

```diff
-import { Public_Sans } from "next/font/google";
+import { Noto_Serif, Public_Sans } from "next/font/google";
```

```diff
 const publicSans = Public_Sans({
   variable: "--font-public-sans",
   subsets: ["latin", "vietnamese"],
   display: "swap",
 });
+
+const notoSerif = Noto_Serif({
+  variable: "--font-noto-serif",
+  subsets: ["latin", "vietnamese"],
+  display: "swap",
+});
```

```diff
-      <body className={`${publicSans.variable} antialiased`}>
+      <body className={`${publicSans.variable} ${notoSerif.variable} antialiased`}>
```

### 7. `src/app/globals.css`, dòng 60

```diff
-  --font-serif: Georgia, "Times New Roman", serif;
+  --font-serif: var(--font-noto-serif), Georgia, "Times New Roman", serif;
```

**Vì sao chọn Noto Serif:** trong dữ liệu font của Next, font này có subset `vietnamese` và bản variable, nên không phải khai báo weight. Cách nạp giống hệt `Public_Sans` ngay phía trên, `next/font` tự host nên không thêm dependency.

**Vì sao sửa ở biến CSS:** một dòng sửa cho cả 13 chỗ dùng `.display`, không phải đụng từng trang. Georgia được giữ làm font dự phòng.
