## Nguyên nhân

Trình duyệt gửi `POST /auth/login` kèm `Origin: http://localhost:3003` tới proxy của storefront. Proxy sao chép mọi header, trừ danh sách `STRIP`, nên `Origin` đi tiếp tới gateway. Gateway coi đây là request CORS và chỉ cho phép `http://localhost:3000` (`api-gateway application.yml:162`). Mọi port khác nhận 403 với body rỗng.

Comment ở `route.ts:8-11` nói rõ proxy tồn tại để không phải phụ thuộc CORS, nhưng code lại làm lộ `Origin` cho gateway.

## Thay đổi

### 1. `src/app/api/[...path]/route.ts`, dòng 23-34

Thêm `origin` vào danh sách header bị loại.

```diff
 const STRIP = new Set([
   "connection",
   "content-length",
   "host",
   "keep-alive",
+  // Server-to-server: without this the gateway applies browser CORS rules to our port.
+  "origin",
   "transfer-encoding",
   "upgrade",
```

**Vì sao sửa ở đây:** `Origin` mô tả trang web đang gọi, và trang đó chỉ gọi cùng origin với proxy. Từ proxy tới gateway là gọi server với server, nên header này không còn ý nghĩa. Không có `Origin`, CORS filter của gateway bỏ qua request.

**Vì sao không mở rộng CORS ở gateway:** cách đó phải khai báo từng port dev và từng domain deploy, đúng điều mà comment ở `route.ts` muốn tránh. Biến `CORS_ALLOWED_ORIGINS` dùng lúc kiểm thử chỉ là cách né tạm, sửa xong thì bỏ.

### 2. `e2e/api/storefront.spec.ts`, thêm test vào cuối file

```ts
test("the proxy keeps the browser's origin away from the gateway", async ({
  request,
}) => {
  const response = await request.post("/api/v1/auth/login", {
    headers: { origin: "https://not-whitelisted.example" },
    data: { email: "nobody@example.com", password: "wrong-password" },
  });
  expect(response.status()).not.toBe(403);
});
```

**Vì sao viết ở mức request:** `route.ts` kéo theo `import "server-only"` từ `backend-base.ts`, nên Playwright không import trực tiếp được. Test này chỉ có giá trị khi gateway đang chạy. Nếu không có gateway, proxy trả 502 và test vẫn pass.
